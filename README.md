# 🎗️ تفاؤل — مغامرة الأبطال الصغار

لعبة مغامرات حركية تفاعلية للتوعية بمرض السرطان والعادات الصحية، مصممة للأطفال واليافعين من عمر **7 إلى 14 سنة**، باللغة العربية بالكامل.

## 🎮 كيف تلعب؟

افتح ملف `index.html` في أي متصفح (على الحاسوب أو الجوال) — لا تحتاج إلى إنترنت أو أي تثبيت.

- اكتب اسمك واختر شخصيتك (ولد 👦 أو بنت 👧) — الشخصية تحمل اسمك وتتحرك معك!
- حرّك البطل بين المسارات الثلاثة: **الأسهم ⬅️➡️** على الحاسوب، أو **الأزرار / لمس جانبي الشاشة** على الجوال.
- **اجمع** العناصر الصحية 💚 و**تجنب** الضارة 🚫 و**احذر العقبات** ⚠️ فهي تخسرك قلباً كاملاً!

## 🗺️ مسار المغامرة (يُفتح بالتتابع)

| # | البيئة | ماذا يتعلم الطفل؟ |
|---|--------|-------------------|
| 1 | 🏠 المنزل | الماء والفواكه والنوم المبكر، وخطر التدخين السلبي |
| 2 | 🏫 المدرسة | غسل اليدين والفطور الصحي، والسرطان ليس معدياً |
| 3 | 🛒 السوبرماركت | اختيار المشتريات الصحية بدل المصنّعة والمقلية |
| 4 | 🌳 الحديقة | واقي الشمس والقبعة، وساعة حركة يومياً |
| 5 | 🎗️ مهرجان التوعية | رسائل الأمل ودعم المرضى ومحاربة الخرافات |

## ⚙️ آليات اللعب الحماسية

- 💚 **مؤشر الصحة**: يرتفع ويخضرّ مع كل عنصر صحي، وينخفض ويحمرّ مع الضار — إذا وصل للصفر تخسر قلباً!
- ❤️❤️❤️ **ثلاثة قلوب (فرص)**: العقبات الخاصة (🚬 الدخان، 🦠 الجراثيم، ☀️ الشمس الحارقة...) تخصم قلباً مباشرة
- 🗝️ **بوابات المعرفة**: سؤالان توعويان في نهاية كل بيئة لفتح الطريق ونقاط إضافية
- ⭐ **النجوم**: عدد القلوب المتبقية عند إنهاء المهمة = عدد نجومك (حتى 3 نجوم)
- 🔓 **مسار متدرج**: كل بيئة تفتح التي بعدها، والصعوبة تزداد تدريجياً
- 🎓 **شهادة "بطل التوعية"** باسم اللاعب عند إكمال المسار كاملاً
- 💾 يُحفظ تقدمك تلقائياً في المتصفح

## 💜 الرسائل التربوية الأساسية

1. السرطان **ليس معدياً** أبداً.
2. المرض **ليس ذنب أحد** وليس عقاباً.
3. **الاكتشاف المبكر** يجعل العلاج أسهل وأنجح.
4. العادات الصحية (الغذاء، الحركة، النوم، الحماية من الشمس، الابتعاد عن الدخان) تحمي أجسامنا.
5. الصديق الحقيقي **يدعم** صديقه المريض ولا يبتعد عنه.
6. الأمل موجود دائماً — كثيرون يُشفون ويعودون لحياتهم. 🌟
