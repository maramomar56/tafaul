# 🎗️ تفاؤل — رحلة الأبطال الصغار

لعبة تفاعلية توعوية عن مرض السرطان، مصممة للأطفال واليافعين من عمر **7 إلى 14 سنة**، باللغة العربية بالكامل.

## 🎮 كيف تلعب؟

افتح ملف `index.html` في أي متصفح (على الحاسوب أو الجوال) — لا تحتاج إلى إنترنت أو أي تثبيت.

## 🗺️ مراحل اللعبة

| المرحلة | النوع | ماذا يتعلم الطفل؟ |
|---------|-------|-------------------|
| 🔬 ما هو السرطان؟ | قصة مصورة + اختبار | شرح مبسط للخلايا والمرض بأسلوب غير مخيف |
| 🥦 أبطال العادات الصحية | لعبة فرز | التمييز بين العادات الصحية والضارة للوقاية |
| 🕵️ حقيقة أم خرافة؟ | لعبة تحقيق | تصحيح المفاهيم الخاطئة (السرطان ليس معدياً، ليس ذنب أحد...) |
| 🤝 الصديق الداعم | مواقف وخيارات | التعاطف ودعم الأصدقاء المرضى |

## ✨ المميزات

- 🎯 نظام نقاط ونجوم (حتى 3 نجوم لكل مرحلة) لتشجيع الإعادة والتعلم
- 🎓 شهادة "بطل التوعية" باسم اللاعب عند إكمال جميع المراحل
- 🎊 مؤثرات احتفالية وأصوات تفاعلية
- 💬 تغذية راجعة تعليمية بعد كل إجابة (صحيحة أو خاطئة) بأسلوب مشجع لا يُحبط
- 📱 تصميم متجاوب يعمل على الجوال والحاسوب
- 🔤 واجهة عربية كاملة (RTL)

## 💜 الرسائل التربوية الأساسية

1. السرطان **ليس معدياً** أبداً.
2. المرض **ليس ذنب أحد** وليس عقاباً.
3. **الاكتشاف المبكر** يجعل العلاج أسهل وأنجح.
4. العادات الصحية (الغذاء، الرياضة، النوم، الابتعاد عن التدخين) تحمي أجسامنا.
5. الصديق الحقيقي **يدعم** صديقه المريض ولا يبتعد عنه.
6. الأمل موجود دائماً — كثيرون يُشفون ويعودون لحياتهم. 🌟
