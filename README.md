# 🎗️ تفاؤل — مغامرة الأبطال الصغار

لعبة تفاعلية للتوعية بمرض السرطان والعادات الصحية، مصممة للأطفال واليافعين من عمر **7 إلى 14 سنة**، باللغة العربية بالكامل — **كل بيئة فيها لعبة مختلفة تماماً** بأسلوب غامر.

## 🎮 كيف تلعب؟

افتح ملف `index.html` في أي متصفح (حاسوب أو جوال) — بدون إنترنت وبدون تثبيت.
اكتب اسمك واختر شخصيتك (ولد 👦 / بنت 👧) وستحمل الشخصية اسمك داخل كل الألعاب.

## ⚙️ عناصر الحماس المشتركة

- 💚 **مؤشر الصحة**: يرتفع ويخضرّ مع كل قرار صحيح، وينخفض ويحمرّ مع الخطأ — وصوله للصفر يخسرك قلباً
- ❤️❤️❤️ **ثلاثة قلوب (فرص)** في كل بيئة — نفادها يعني إعادة المهمة
- ⭐ **النجوم**: القلوب المتبقية عند الفوز = نجومك (حتى 3 لكل بيئة)
- 🔓 **مسار متدرج**: كل بيئة تفتح التي بعدها على خريطة مسار متعرج
- 🎓 **شهادة "بطل التوعية"** باسم اللاعب عند إكمال المسار كاملاً
- 💾 حفظ تلقائي للتقدم في المتصفح + مؤثرات صوتية واحتفالية

## 💜 الرسائل التربوية الأساسية

1. السرطان **ليس معدياً** أبداً.
2. المرض **ليس ذنب أحد** وليس عقاباً.
3. **الاكتشاف المبكر** يجعل العلاج أسهل وأنجح.
4. العادات الصحية (الغذاء، الحركة، النوم، الحماية من الشمس، الابتعاد عن الدخان) تحمي أجسامنا.
5. الصديق الحقيقي **يدعم** صديقه المريض ولا يبتعد عنه — وشعره سينمو من جديد.
6. الأمل موجود دائماً — ملايين شُفوا وعادوا لحياتهم. 🌟
